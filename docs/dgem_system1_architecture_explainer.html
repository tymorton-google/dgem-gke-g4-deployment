Architecture Blueprint #1 • Cloud Infrastructure & Storage Topology

GKE G4 Inference Runtime, 3-Tier ComputeClass & Stage-2 Vertex AI Cascade

End-to-end Google Cloud deployment topology showing how stateless CPU gateway pods (`dgem serve`) orchestrate single-pass GPU inference on `g4-standard-48` nodes, recover from Spot preemptions in seconds via 3-layer Hyperdisk + `/dev/shm` caching, and selectively escalate high-entropy slots to Vertex AI `gemini-3.5-flash-lite`.

Why G4 (`RTX PRO 6000 Blackwell`) Fits System-1

  • Native SM120 FP4 Tensor Cores: Executes `ModelOpt NVFP4 (W4A4)` weights natively with `17.53 GiB` footprint out of `96 GB GDDR7` VRAM.
  • Massive KV Cache Headroom: Over `78 GiB` of free VRAM remains for batched multi-slot retail prompts and SigLIP image tokens.
  • Constant $O(1)$ Step Latency: 4-slot structured decisions complete in `57 ms` p50 (`67 ms` p99).

3-Layer Spot Recovery (`87.6s` → `7.91s`)

  • Layer 1 (Secondary Boot Disk): Pre-caches the `20 GB` vLLM runtime container image so Spot replacement nodes pull `0 bytes` over the network.
  • Layer 2 (Hyperdisk Snapshot / ML): Pre-hydrated `VolumeSnapshot` streams `17.53 GiB` of NVFP4 safetensors into `/dev/shm` in `7.91 s` (`11.1x` faster than cold GCS).
  • Layer 3 (SM120 JIT Cache): Restores pre-compiled FlashInfer CUDA kernels (`jit-cache.tar.gz`) in `< 1 s`, eliminating the 90-second first-request compile stall.

3-Tier ComputeClass Resilience

  • Priority 1 (GKE Spot G4): Primary execution tier capturing 60–91% GPU cost savings against On-Demand pricing.
  • Priority 2 (DWS Flex-Start): Dynamic Workload Scheduler provisions fallback G4 capacity during regional Spot tightness.
  • Priority 3 (On-Demand + Active Migration): Guarantees production SLA and automatically migrates back to Spot when capacity frees up.
Architecture Blueprint #2 • Algorithmic & Mathematical Mechanics

How the System-1 Discrete Diffusion Engine (`DiffusionGemma 26B-A4B NVFP4`) Works

Unlike autoregressive LLMs that decode one token at a time ($O(N)$ sequential forward passes) and suffer from poorly calibrated verbalized confidence, `DiffusionGemma` treats structured multi-slot decision-making as a single-pass bidirectional denoising problem ($O(1)$ forward pass) over a fixed 128-token canvas, yielding exact per-slot probability distributions in `57 ms`.
